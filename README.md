# Портал сотрудников ЦИК России - Обновлённая версия

## 🎉 Новые функции

### 1. 📄 Система управления документами с модерацией
- **Добавление документов**: Любой пользователь может загрузить документ
- **Модерация**: Документы отправляются на модерацию администратору или владельцу
- **Статусы документов**:
  - 🟡 На модерации (ожидает одобрения)
  - 🟢 Одобрен (опубликован)
  - 🔴 Отклонён (с указанием причины)
- **Права доступа**:
  - Все пользователи могут загружать документы
  - Админы и владельцы могут одобрять/отклонять документы
  - Только админы и владельцы могут удалять одобренные документы

### 2. ✅ Система задач с назначением
- **Создание задач**: Админы и владельцы могут назначать задачи другим пользователям
- **Управление задачами**:
  - Начать выполнение (pending → in_progress)
  - Завершить задачу (in_progress → completed)
  - Переоткрыть задачу (completed → pending)
  - Удалить задачу
- **Приоритеты**: Низкий, Средний, Высокий
- **Отображение**: Все задачи отображаются на главной странице в разделе "Мои задачи"

### 3. 📅 Календарь событий (только для владельца)
- **Добавление событий**: Только владелец может добавлять новые события
- **Удаление событий**: Владелец может удалять события
- **Типы событий**: Заседания, Работа, ВКС, Семинары, Сроки
- **Визуализация**: Цветовая маркировка на календаре

### 4. 👥 Управление контактами (только для владельца)
- **Редактирование подразделений**: Владелец может изменять информацию о подразделениях
- **Добавление подразделений**: Создание новых записей в списке контактов
- **Удаление подразделений**: Удаление ненужных записей
- **Индикатор режима**: При входе владельца отображается "Режим редактирования"

### 5. 📝 Система регистрации с модерацией
- **Форма регистрации**: Доступна всем пользователям
- **Обязательные поля**: Логин, ФИО, Email, Обоснование
- **Модерация**: Админы и владельцы рассматривают заявки
- **Действия модераторов**:
  - Одобрить заявку
  - Отклонить заявку (с указанием причины)
- **Уведомления**: Счётчик заявок на рассмотрении для админов

### 6. 🔐 Обновлённая система ролей

#### Владелец (Owner) - @Zona
- ✅ Полный доступ ко всем функциям
- ✅ Выдача ролей admin и owner
- ✅ Изменение должностей пользователей
- ✅ Управление пользователями
- ✅ Модерация документов
- ✅ Модерация регистраций
- ✅ Добавление событий в календарь
- ✅ Редактирование контактов
- ✅ Назначение задач

#### Администратор (Admin)
- ✅ Управление пользователями (кроме выдачи роли admin)
- ✅ Изменение должностей пользователей
- ✅ Модерация документов
- ✅ Модерация регистраций
- ✅ Назначение задач
- ❌ **НЕ может выдавать роль admin** (только владелец)
- ❌ Не может добавлять события в календарь
- ❌ Не может редактировать контакты

#### Редактор (Editor)
- ✅ Загрузка документов (на модерацию)
- ✅ Просмотр статистики
- ✅ Редактирование новостей
- ✅ Выполнение назначенных задач
- ✅ Подача заявки на регистрацию
- ❌ Не может модерировать документы
- ❌ Не может назначать задачи

#### Просмотр (Viewer)
- ✅ Просмотр статистики
- ✅ Выполнение назначенных задач
- ✅ Подача заявки на регистрацию
- ❌ Ограниченный доступ к функциям

## 🚀 Быстрый старт

### Вход в систему
1. Откройте приложение
2. Нажмите "Быстрый доступ (демо)" на экране входа
3. Выберите пользователя:
   - **@Zona** - Владелец (полные права)
   - **@ivanov_ps** - Администратор
   - **@smirnova_ev** - Редактор
   - **@petrova_mi** - Просмотр

### Проверка новых функций

#### Как владелец (@Zona):
1. **Документы**: Загрузите документ → он появится в "На модерации"
2. **Задачи**: Назначьте задачу другому пользователю через кнопку "Назначить задачу"
3. **Календарь**: Добавьте новое событие через кнопку "Добавить событие"
4. **Контакты**: Наведите на подразделение → появятся кнопки редактирования/удаления
5. **Регистрация**: Перейдите во вкладку "Регистрация" → увидите заявки на модерации

#### Как админ (@ivanov_ps):
1. **Документы**: Одобрите или отклоните загруженные документы
2. **Задачи**: Назначайте задачи другим пользователям
3. **Пользователи**: Меняйте должности, но НЕ можете выдавать роль admin
4. **Регистрация**: Рассматривайте заявки на регистрацию

#### Как редактор (@smirnova_ev):
1. **Документы**: Загрузите документ → он отправится на модерацию
2. **Задачи**: Выполняйте назначенные задачи (кнопки "Начать", "Завершить")
3. **Регистрация**: Подайте заявку на регистрацию

## 🔒 Безопасность

- **Разграничение прав**: Каждая функция проверяет права текущего пользователя
- **Защита от изменений**: Админ не может изменить роль другого админа или владельца
- **Модерация**: Критические действия (документы, регистрации) требуют одобрения
- **Владелец**: Единственный пользователь с полным контролем над системой

## 📝 Примечания

- Все данные хранятся в состоянии React (при перезагрузке страницы сбрасываются)
- Для продакшена рекомендуется подключить базу данных и бэкенд
- Система готова к интеграции с реальным API
